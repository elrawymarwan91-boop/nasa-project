## How to use
After starting a campaign and entering the outpost, use the top navigation to switch workspaces. The vehicle workspaces share the same authoritative backend campaign state.

## Important simulation boundaries
The spacecraft workspace is an interactive mission-systems cockpit using current campaign telemetry; it is not an independent spacecraft flight simulator. Orbital mechanics, propulsion, attitude control, rendezvous and radio delay are not implemented.

The rover workspace lets the player choose and dispatch a surface survey using the existing backend mission model. Trips progress when the player advances a Sol; it is not a real-time driving simulator. Steering, traction, suspension, collision, route pathfinding and accurate Gale Crater geospatial mapping are not implemented.

The cockpit viewport is original CSS scene artwork designed to create a cockpit / windshield impression. It is not a 3D model or a replica of a NASA vehicle.
